CNG Online Slot Booking System (COSB)

Project Description:-
The CNG Online Slot Booking System is a modern web-based application developed to simplify and digitize the process of booking CNG refueling slots.  
The system helps users avoid long waiting queues by allowing them to check real-time slot availability, book refueling appointments online, and make secure digital payments.
It provides a smooth, user-friendly, and eco-friendly solution for both vehicle owners and CNG station operators.

Academic Information:-
This project was developed as part of my 5th semester Project-Based Learning (PBL) course.
It was developed to understand full-stack web development concepts, real-time booking systems, and digital payment integration.

Features:-
- User Registration & Login
- Real-time Slot Availability
- Online CNG Slot Booking
- Booking Cancellation & Rescheduling
- Secure Online Payments
- QR/Token Based Confirmation
- Admin Dashboard for Station Management
- SMS/Email Notifications
- Responsive User Interface

Technologies Used:-
- React.js
- Node.js
- Express.js
- MongoDB / MySQL
- HTML
- CSS
- JavaScript
- Razorpay / Paytm API
